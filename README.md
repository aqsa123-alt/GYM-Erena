# Elite Arena - Multi-Discipline Sports & Fitness Club ⚡

A high-performance, dark-themed responsive website for Elite Arena Sports Club featuring:
- **Olympic-Grade Badminton Courts** (BWF-Standard)
- **World-Class Strength & Conditioning Gym**
- **Championship Boxing & Combat Arena**

## 🚀 Live Pages
- `index.html` - Main Club Showcase, Memberships, & Schedule
- `gym.html` - Strength Arena, Free Weights, & Conditioning Zone
- `boxing.html` - Boxing Ring, Combat Slabs, & Heavy Bag Rails
- `badminton.html` - BWF Synthetic Courts & Tournament Telemetry

## 🛠️ Run Locally
```bash
# Start the local server
node server.js
```
Then open [http://localhost:3000](http://localhost:3000) in your browser.
